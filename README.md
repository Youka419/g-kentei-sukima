# G検定 スキマ学習

[JDLA公式「G検定とは」](https://www.jdla.org/certificate/general/) のシラバス（G2024#6〜）に沿った用語アプリです。スマホでは **章を選ぶ → 3 / 5 / 10 / 15問** ですぐ解けます。

講座PDFは公開物に含めていません。解説は公式キーワードの短い独自まとめです。

## スマホでの使い方

1. 上のメニューで「章から学ぶ」
2. 章のカードで **3問 / 5問 / 10問 / 15問** をタップ
3. 間違えたら「弱点ノートに追加」
4. 「履歴」で正答率・章ごとの進み・直近の解答を確認
5. 各章の下、またはページ最下部の **用語集** から定義を一覧
6. 「弱点」タブから Excel / Word を端末に保存

公開版のサーバーにはファイルが残りません。履歴は次の順で残します。

1. 同じ端末の同じブラウザなら自動保存
2. パソコンとスマホをまたぐときは、ホームか学習履歴で **引き継ぎコードを発行** し、もう一方で同じコードを入力
3. 予備として `G検定_学習履歴.json` を保存。複数あっても「まとめて復元」で合体します

弱点ノートは Excel / Word を端末に保存してください。

## ローカル起動

```powershell
python -m pip install -r requirements.txt
python -m streamlit run app.py
```
